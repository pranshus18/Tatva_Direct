# Returns and Refunds Policy

Orders may be returned according to supplier acceptance and platform phase-2 returns policy.

- Request a return from your order details while the order is eligible.
- Partial returns may be supported per line item quantity.
- Refunds are processed after the return is acknowledged and closed.
- Damaged or incorrect items should be reported with order number and description.

For voice assistance, say "return policy" or "how do refunds work".
